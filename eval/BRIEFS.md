# Member modeling paired briefs — frozen before runs

Each condition uses Claude Code with the same model, Rhino 8, JsonToGH bridge,
time allowance and agent prompt. Repeat each brief twice. Condition A receives
local canvas and workbench tools only. Condition B receives the same local tools,
the granted nuLUCA cloud tools and the member modeling guidance. The agent may
use its normal web search in both conditions. Save each result as a `.ghx` and
record the source `.json`, tool transcript, wall time and live solve result.

## B1 — helical stair

Build an editable helical stair with 14 treads over a 2,800 mm rise and a
handrail supported by balusters. Expose named controls for tread count and
total rise. The default total rise must be within 1 mm of 2,800 mm. Changing
tread count must change the tread geometry; changing rise must move the top
landing and baluster/rail height accordingly.

## B2 — ribbed pendant

Build an editable pendant shade 460 mm across with 24 radial ribs and a central
opening 90 mm across. Expose named controls for rib count and opening diameter.
At the defaults, overall diameter must be within 1 mm of 460 mm. Both controls
must change the intended geometry when adjusted.

## B3 — biological shading screen

Build a 3,000 × 2,400 mm facade shading screen whose aperture pattern follows
one researched biological strategy. Expose named controls for aperture count
and overall openness. Include a plainly comparable uniform-perforation
baseline in the definition or the recorded design note. Explain what the
biological analogy contributes and where it stops; do not claim performance
that has not been measured. Outer dimensions must be within 1 mm of the brief.
